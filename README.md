# Tiptop Tyres & Wheels

Website for tyre fitting and wheel alignment in Mount Druitt, NSW.

## Development

Install dependencies with Bun, then start the development server:

```sh
bun install
bun run dev
```

## Build and test

```sh
bun run build
bun run test
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
